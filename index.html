About

gratools. is a solo project making free, open source tools for anyone to use. I got tired of paying for tools, so I'm building them myself and giving them away.

Free, really

Every tool is 100% free. No sign-up, no paywall and no ads.

Open source

The code is public on GitHub, so you can read it, fix it, or make your own version.

Made possible with AI

AI helps design, write and test the tools, which is how one person can build them. gradesign. is built with GPT 6 Astra.

What the name means

The name joins "gratis", the Latin word for free of charge, with "tools". It means tools that cost nothing.
